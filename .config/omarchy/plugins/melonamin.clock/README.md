# World Clock

User-owned clone of Omarchy's stock clock. It keeps the original bar clock,
calendar, format cycling, week-start toggle, and life/year progress features.

The calendar popup adds a collapsed **World time** section for:

- Berlin — `Europe/Berlin`
- Moscow — `Europe/Moscow`
- Dubai — `Asia/Dubai`

Click the section header or press `Z` while the popup is open to toggle it.
Times refresh once per minute and use the system IANA timezone database, so
daylight-saving changes are applied automatically.
